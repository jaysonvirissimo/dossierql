## Findings and what was done

### Fixed

1. **The quarry's dossier was headed "operative 1, not yet identified"**
   when a query had not asked for `codename` (found by the end-to-end test
   before the runs). The briefing gives the quarry's codename, so the
   dossier is now headed with it.
2. **The assessment's debrief and reference spoke of a landlady** whom no
   response identifies (clean-room, _The Courier's Guidebook_). Both now
   speak of the witness.
3. **Nothing on the assessment's screen said how to write quotation marks
   inside a statement** (clean-room and novice, _The Courier's
   Guidebook_). `SearchApplication.statement` now says that a statement
   with quotation marks of its own can be written as a block string. The
   teaching case's briefing already taught it, but a player who arrives by
   placement reads only the documentation.
4. **At a warrant stage filed from the terminal, the Operative box looked
   as if it had to be filled first** (three runs). The panel now says that
   choosing an operative in the box files nothing, and that the box shows
   which operative the claims are about.
5. **The urgency of a search seemed to have no stakes** (novice, _The
   Courier's Guidebook_). The description of `ROUTINE` now says that a
   routine search of watched premises comes too late and finds nothing.
6. **`following` on `fileTravelOrder` did not say which record it takes**
   (novice, _The Courier's Guidebook_). It now says the record chosen first
   on the travel order, such as a journey or a find.
7. **The assessment's debrief used "block string" and "default value"
   without a gloss** (novice, _The Courier's Guidebook_). Both now link to
   the glossary, with a clause each.
8. **The Lisbon briefing made `leftBy` sound like text** (novice, _The
   Handler's Road_). It now says that `leftBy` returns a record of its own,
   opened with braces.
9. **"Quotes the porter word for word" left open whether the statement
   could say more** (novice, _The Handler's Road_). The Tangier briefing now
   says the statement contains the porter's words exactly and may say more
   around them.
10. **The Valletta paragraph on urgency took two readings** (novice, _The
    Handler's Road_). It now says first that the watched premises are the
    one GILT_MAGPIE left within the hour, and then the rule.
11. **The documentation did not explain `= ROUTINE` after a box** (novice,
    _The Handler's Road_). A box with a default value now says what the
    value after `=` is.
12. **The documentation called `reasons: [String!]!` a single value**
    (novice, _The Handler's Road_). A list of values is now described as a
    list. This was true of every list of values since clearance 1.

The changed passages were read by a fresh reader who did not know the
answers, and revised from what that reader reported.

### Logged, with the reason each stands

- **A player can solve Valletta without a request that relies on the
  default value** (novice, _The Handler's Road_). The step is the
  declaration `$urgency: Urgency = ROUTINE`, which the briefing gives and
  validation finds in the reference solution. A routine search of the
  Harbour Hotel turns up the ticket to Marseille, which a player who
  searches the premises in order meets. Making the routine search
  necessary would add a record to a stage that already introduces one
  step. Revisit if the sessions with beginners show the default value is
  not understood.
- **The warrant's evidence chain is not shown, because the case goes
  straight to the debrief** (both clean-room runs). Every case's last form
  does the same. The debrief is the place for the outcome.
- **The variables panel's values are reported for a request that declares
  none** (novice, _The Handler's Road_). The label states what was sent
  with the request, as SDD 8.2 says. This predates clearance 12.
- **The destination box keeps every country from earlier stages**
  (clean-room, _The Handler's Road_). The box offers every record of its
  type that the player has retrieved, which is how a form shows that it
  gives nothing away. This predates clearance 12.
- **Dropdown options were reported as "disabled" in the accessibility
  tree** (both clean-room runs). The options carry no `disabled`
  attribute, and the runners could choose them. Recorded as a quirk of the
  agents' snapshot tool, to be checked with a screen reader.
- **A duplicate transmission** (clean-room, _The Handler's Road_) came from
  the runner's tool setting the editor while a tab changed. It was not
  reproduced in the end-to-end tests.
- **The travel button and `fileTravelOrder` both file a travel order**
  (two runs). Both have been available since clearance 11, and SDD 6.2
  says they call the same action.
- **The Tangier search came close to the weight limit** (novice, 185 of 200) when the request asked for every country of each find's language.
  The reference solution is under the limit, and the clerk's note explains
  a refusal at no cost.
- **Ruling out had no explanation in Valletta** (novice). Ruling out has
  been a mechanic since _The Guest Register_.
- **The dispatch header names the find, not the country** (novice). The
  header names the lead, as it does in every case.

## Caveats

An agent that solves a case shows that the screen holds enough to solve it.
It does not show that a beginner will find it, or how long that takes (SDD
section 9). Each runner knew GraphQL, and the novice runs say where they
leaned on JSON habit rather than the screen: one escaped quotation marks
inside a variable instead of writing a block string. No run had a search
refused, a warrant rejected, or a `@oneOf` form returned.
